# Справжня IP-адреса клієнта за CDN

- Журнали, обмеження частоти запитів і бекенди бачать адресу відвідувача, а не вузол CDN чи шлюз Docker.
- Пресети для Cloudflare, Akamai, AWS CloudFront і Fastly завантажують актуальні діапазони провайдера під час кожного запуску, тож список довіри ніколи не застаріває; заголовок з IP клієнта обирається під провайдера.
- Набори довіри поєднуються: CDN перед іншим зворотним проксі визначає справжнього клієнта і на прямому, і на проксійованому шляху.
- Проксійовані бекенди отримують рівно одну визначену адресу клієнта, ніколи не сирий ланцюжок пересилань.
- Помилково вказаний провайдер не дає контейнеру запуститися; недоступний список провайдера лише попереджає і зберігає інші джерела.
