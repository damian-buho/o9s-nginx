# Автоматичні підказки ресурсів

- Під час запуску сканує стилі, скрипти, зображення та шрифти сайту й надсилає заголовки попереднього завантаження, тож браузер починає їх отримувати ще до розбору HTML.
- Кожен тип ресурсів вмикається окремо; сканування вмикається за бажанням.
- Підказки preconnect і dns-prefetch для сторонніх джерел задаються списком через кому.
