# Переспрямування для перенесених сторінок

- Сайт зберігає старі адреси після перейменування: кожна перенесена сторінка відповідає постійним переспрямуванням на нову адресу, і пошукові системи переносять її позиції.
- Переспрямування постачаються файлом `_redirects` усередині опублікованого сайту, у форматі, який читають Netlify і Cloudflare Pages, тож змінюються разом зі сторінками, на які вказують.
- Публікація, що підміняє сайт, застосовує нові переспрямування без перезапуску.
- Хибний рядок пропускається й називається в журналі; він ніколи не зупиняє решту сайту.
