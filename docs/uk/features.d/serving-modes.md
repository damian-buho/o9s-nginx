# Готові режими обслуговування

- Одне налаштування визначає, як обслуговується сайт: статичні файли, PHP-застосунок через FastCGI, статичні файли з переходом на бекенд застосунку або перелік вмісту каталогу.
- Адреса бекенду визначається під час запиту, тож nginx запускається, навіть якщо застосунок ще не готовий.
- Оновлення до WebSocket і заголовки пересилання працюють через проксі без додаткової конфігурації.
- Дочірні образи додають власні режими одним файлом шаблону.
