# Перевірка конфігурації та перевірки стану з урахуванням nginx

- Згенерована конфігурація перевіряється до запуску nginx; у разі помилки кожен згенерований файл потрапляє в журнал, тож хибний рядок видно в журналі контейнера.
- Перевірки стану опитують сам nginx і виконують справжній HTTP-запит, а не лише перевіряють наявність процесу.
- Є кінцева точка готовності для балансувальників навантаження та оркестраторів.
- Команда налагодження виводить повну чинну конфігурацію з розгорнутими include.
