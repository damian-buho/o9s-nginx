# Попереднє стиснення статичних ресурсів

- Статичні файли стискаються один раз, з максимальним ступенем, у gzip, brotli і zstd; nginx віддає готовий файл без витрат CPU на кожен запит.
- Виконується під час збірки й успадковується дочірніми образами; також може виконуватися під час запуску контейнера для вмісту з тома.
- Може стежити за змонтованим каталогом релізів і самостійно перестискати вміст, коли підставлено новий реліз.
- Окрема команда стискає будь-який каталог уручну.
