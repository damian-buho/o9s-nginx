# Налаштування лише через змінні оточення

- Кожне налаштування nginx має розумне значення за замовчуванням і змінну оточення для перевизначення — образ працює без змонтованих файлів конфігурації.
- Порти, TLS, стиснення, проксіювання, кешування, журнали, заголовки безпеки й трасування налаштовуються з `docker run` або compose.
- Додаткові можливості (CORS, заголовки безпеки, перенаправлення на HTTPS, сертифікати, трасування) вмикаються для кожного сайту переліком, без редагування конфігурації.
