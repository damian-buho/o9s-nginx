# HTTP/3 (QUIC)

- HTTP/3 вкомпільовано й увімкнено за замовчуванням; браузери дізнаються про нього й переходять самі.
- HTTP/2 і HTTP/3 працюють на одному порту.
- Параметри транспорту QUIC і сокетів налаштовуються під час роботи для навантажених серверів.
