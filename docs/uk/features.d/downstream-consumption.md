# Основа для образів на базі nginx

- Один `FROM` успадковує конвеєр збірки, хуки запуску, перевірки стану, сторінки помилок і попереднє стиснення.
- Дочірні образи налаштовуються перевизначенням значень оточення, а не копіюванням чи латанням файлів конфігурації.
- Нові обробники запитів і додаткові можливості додаються одним файлом шаблону в образі; наявна конфігурація лишається недоторканою.
- Scaffold створює новий проєкт на базі nginx, де все перелічене вже під’єднано.
