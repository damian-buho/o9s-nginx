# Локалізовані самодостатні сторінки помилок

- Власні сторінки помилок для десяти стандартних кодів стану (400–504), згенеровані під час збірки з єдиного шаблону замість убудованих сторінок nginx.
- Кожен відвідувач отримує свою мову: сервер узгоджує `Accept-Language` для кожного запиту (англійська, іспанська, українська) з автоматичним поверненням до англійської — без JavaScript.
- Темні за замовчуванням і слідують за світлою/темною перевагою операційної системи через власне перемикання колірної схеми CSS.
- Повністю самодостатні: системні шрифти та без запитів до третіх сторін, тому сторінки виглядають однаково без мережі та за суворої Content-Security-Policy.
- Додати мову — це один файл gettext `.po` — сторінки та узгодження мови розширюються автоматично при наступній збірці.
